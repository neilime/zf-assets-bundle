# AssetsBundle

AssetsBundle manages CSS, JavaScript, Less, SCSS and media assets for Laminas MVC
applications. It compiles styles in development and bundles, minifies and caches
assets in production.

Use PHP 8.4 and a compatible Laminas MVC application. See
[composer.json](composer.json) for the supported dependencies.

```sh
composer require neilime/zf-assets-bundle
```

Follow the [installation and usage guide](docs/usage/README.md) to register the
module, configure asset directories and render or clear the cache.

See the [documentation index](docs/README.md) for development and contribution
instructions.
